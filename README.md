# Семь высоток Москвы

Офлайн-велоквест по семи сталинским высоткам Москвы: наводишь камеру на здание, контур ключа совпадает с верхушкой, и открывается буква слова ИСТОРИЯ.

Сайт-версия приложения (PWA): работает в браузере телефона, а после «Добавить на экран «Домой»» и без интернета.

Адрес сайта: `https://<логин>.github.io/<имя-репозитория>/`

Камера в браузере работает только по HTTPS, GitHub Pages включает его сам.
